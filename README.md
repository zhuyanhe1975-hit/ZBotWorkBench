# ZBot 六类构型实验台

**局域网在线访问：[打开 ZBotWorkBench 前端](http://192.168.13.10:8081/) · [进入强化学习训练](http://192.168.13.10:8081/?training=1)**

基于 React、Three.js 与 MuJoCo WASM 的模块化机器人构型创建与实验工具。研究主线为：连接序列 σ → 关节轴拓扑 → 运动与接触 → 功能验证。

参考：[ZBot 构型功能研究对话](https://chatgpt.com/share/6aa0f22a-9538-83ee-91b8-631f6cb2e845)。六类参数取自对话最终使用真实 ma/mb 网格的方案，功能属于候选假设。

## 启动

需要 Node.js 20.19+。

```bash
npm install
npm run dev
```

打开 http://localhost:3000。无需 Gemini API Key。模型资源位于 `public/assets/ma.obj`、`mb.obj`，MuJoCo WASM 位于 `public/mujoco.wasm`，应与安装的 `@mujoco/mujoco` 版本一致。

暂停时采用按需绘制，静止画面不会持续占用 CPU 重绘；切换到后台标签页会挂起仿真，回来继续，不补算后台时间。性能测量和维护约定见 [CPU 优化说明](docs/performance.md)。

```bash
npm run lint   # TypeScript 静态检查
npm test       # 域模型、正运动学、网格与真实 MuJoCo WASM 回归测试
npm run build  # 生产构建
npm run preview
```

## 强化学习回放（独立前端）

新增可选的**本机强化学习训练**：`npm run build` 后运行 `npm run training`。服务器本机可打开 http://127.0.0.1:8767/?training=1；部署环境可通过 [局域网训练入口](http://192.168.13.10:8081/?training=1) 使用同源反向代理访问。页面自动检测CPU/GPU并管理mjlab训练、停止、续训和结果回放；默认提供已有行走策略微调预设，并保留六自由度从零训练实验任务。详见 [训练说明](docs/training.md)。原静态回放不需要启动此服务。

点击顶部 **强化学习回放**，选择训练任务，点击 **加载策略 → Play**。支持内置示例、浏览器选择本地 `.pt/.pth` 文件，以及允许 CORS 的 HTTP(S) 权重网址。文件在浏览器中解析，不上传。可暂停、单步、重置和调整播放速度；Play 会持续推理，直到手动停止或离开回放。

默认回放使用浏览器 CPU 前馈网络推理和 PhysX WASM（与 Isaac 同类求解器）；MuJoCo 用于几何显示，也可切换为迁移对照引擎。`npm run build` 后，完整 `dist/` 可放到普通静态 HTTP(S) 网站根目录；运行端不需要训练工程、Python、Node 服务、CUDA、GPU 或模型推理服务器。三维显示使用浏览器 WebGL，支持软件渲染环境。不是读取现成录像。

已收录 `zbot_rl_student/pth` 中全部 **15 组原始训练网络**，包括双足各版本、蛇形、鸟形、轮式、速度控制、IMU 学生策略和跑步。15 份导出副本的策略参数相同，未重复列出。12 组通过运动验收；8DOF 双足 v3、6/8DOF 速度控制三组在原生测试中也存在失稳，已标为实验。速度任务提供前进、侧移、转向命令，扩展观测任务使用 PhysX。未知网络仍不能只靠输入维度匹配。

默认 **PhysX WASM** 保留训练用 TGS 求解器、60 Hz 物理步长、50/5 隐式关节驱动、实际凸碰撞体、观测定义与 30 Hz 积分动作接口。双足策略通过连续 20 秒站立和前进验收；蛇形与形态转换任务按各自运动目标验证。浮点与接触实现仍可能使轨迹不同，不复现训练中的接触终止或跌倒自动重置。**MuJoCo 对照模式仍存在 sim-to-sim 差异，原策略可能跌倒。**详见 [回放格式与验证说明](docs/rl-replay.md)。

## 六类构型

每类为六模块开放串联链，有五个连接方位 σ 和六个动作角 q。所有角度在界面和 JSON 中以度表示，传入 MuJoCo 的状态和控制目标转换为弧度。

| 构型 | σ / ° | 初始 q / ° | 候选研究任务 |
|---|---|---|---|
| 平面型（平行轴） | 0, 0, 0, 0, 0 | 0, 35, 35, 35, 35, 0 | 卷曲、钩挂 |
| 正交型 | 180, 180, 180, 180, 180 | 0, 55, -55, -55, 55, 0 | 空间弯曲、蛇形运动 |
| 同手性螺旋型 | 90, 90, 90, 90, 90 | 55, 55, 55, 55, 55, 55 | 螺旋姿态、包覆 |
| 异手性均衡型 | 90, 270, 90, 270, 90 | 35, 55, -35, -55, 35, 55 | 空间可达、操作 |
| 腿型（单腿链） | 180, 180, 0, 180, 0 | 0, 80, 0, -120, 0, 50 | 落足、抬升、支撑 |
| 功能分区型 | 0, 180, 180, 90, 0 | 0, 0, 90, 90, 60, 60 | 灰色支撑段、蓝色定位段、绿色操作段 |

前四类按连接排列分类，后两类按任务组织分类，因此可交叉。当前没有闭环约束、多足分支、足板或攀爬环境。

## 使用流程

1. 点击顶部或右侧六类构型卡片。默认固定基座、暂停在初始 q，可先检查形状和关节轴。
2. “串联编辑”中编辑 σ、q、轴向，插入、删除、排序模块。支持 1–24 模块；q 随模块身份保留。当前只有一个输出对接面，不允许重叠分支、循环和断链。
3. “基座与保存”设置固定/自由基座、位置、姿态，并本地保存或导出、导入构型 JSON。编辑会暂停并重建模型；点击预设可恢复参考参数。
4. 手动滑块在初始暂停状态直接预览姿态；动力学启动后成为伺服目标。运行后暂停再调节只改变目标，不直接改写已运行状态。重置回到保存的初始 q。波形围绕手动角度偏置振荡，波形名称不保证任务成功。
5. 自由基座用于接地实验。初始化会在必要时整体抬升，避免模型开始就穿入地面。改变摩擦、Kp、自碰撞设置会暂停并重置，防止混合实验条件。
6. “分析与实验记录”显示初始轴系夹角、设计末端和仿真末端、当前接触数及驱动力矩。记录当前快照，最多保留 50 条，刷新前导出。CSV用于测量比较，完整JSON包含构型、控制参数、物理选项、测量和当时XML。若用自定义CAD，还需在资产管理中单独下载两份OBJ。
7. 导出的 XML 带有 `initial` 关键帧。在独立 MuJoCo 查看器中选择该关键帧，即可恢复候选初始 q；本实验台导入后自动使用它。
8. 自定义 XML 的步态控制支持单位传动比的铰链位置执行器。该模式下物理参数以 XML 为准；切换预设或编辑构型返回自动生成模式。

## 建模约定与结果边界

- 模块节距 `L = 0.106 m`，铰链中心 `h = (0,0,0.053)`，标准轴 `u = (0,-1,1)/√2`。
- `Tma = Tin`；`Tmb = Tin · T(h) · R(u,q) · T(-h)`；`Tnext = Tmb · Tz(L) · Rz(σ)`。原始网格不会被拉伸或用虚构连杆代替。
- 标准轴相邻夹角满足 `cos α = (1 + cos σ)/2`，因此 σ=90° 对应夹角60°，σ=180°才对应正交轴。
- 碰撞采用 OBJ 凸包近似，视觉几何不重复计入质量。默认关闭自碰撞；可启用非相邻自碰撞，直接连接的相邻刚体仍排除。
- 速度与累计路程是根基座测量，不是质心速度或净前进距离。力矩是 `qfrc_actuator`，不是位置控制目标。接触数量不等于稳定性指标。
- 材料密度、摩擦、增益与驱动能力未按实物标定，不能据此直接宣称攀爬、负载能力或稳定行走已经实现。实际接口能否锁定0°/90°/270°也需要CAD或实物确认。
- 目前提供姿态、接触和运动实验、正交机械臂局部位姿逆运动学以及状态快照，不包含完整工作空间搜索、力椭球、任务优化或稳定性判据。

关键实现与验证说明见 [docs/implementation.md](docs/implementation.md)。

## 六／七模块机械臂设计筛选

已对 5,120 组离散连接序列粗筛，对 26 组候选作 CAD 凸包碰撞与任务评价，并对五组重点方案完成独立位姿目标复核。第一轮设计报告、可导入构型和数据见 [results/arm-design/README.md](results/arm-design/README.md)。七模块主候选 σ 为 `[180,270,180,180,180,180]°`；这是一轮临时任务下的几何筛选，不是已标定负载或综合最优结论。

运行 `npm run design:screen -- --fresh` 重现粗筛与详细评价，`npm run design:validate` 重现独立目标复核。需要实际质量、力矩和刚度参数后才能继续承载设计。

七模块 ZBot／蛇形／YuMi风格的等包络轴系对照见 [results/architecture-comparison/README.md](results/architecture-comparison/README.md)，运行 `npm run design:compare` 重现。三组使用共同的100×106 mm零位包络代理几何，YuMi风格模型不是ABB原机，其结果不可用于商业产品性能排名。

三组已加入顶部“7DOF 对照”和右侧构型库。点击“7DOF ZBot”“7DOF 蛇形”“7DOF YuMi风格”即可切换，默认固定基座、暂停并启用非相邻自碰撞；ZBot 全关节 ±180°，YuMi 风格沿身体方向 Z 轴 ±180°、横向 Y 轴 ±90°，蛇形所有关节 ±90°。三组从同一末端目标的不同关节解开始，ZBot 使用仓库原始 ma/mb OBJ 模块；蛇形与 YuMi 风格使用沿关节轴布置的圆柱电机壳、轴端、输出叉架及安装法兰，视觉和碰撞共用几何。概念结构每模块标称1 kg，ZBot 沿用原网格密度估算。末端控制、七关节手动调节、运行／重置、实验记录及JSON保存导入均可使用；“基座与保存”提供±90°／±180°统一限位切换。保存文件通过 `geometryMode: "cad"` / `"mechanical"` 保留对应模型；旧版 `"envelope"` 仍可导入；旧文件省略该字段时仍使用原OBJ。

## 所有构型末端控制球

选择任意构型，保留固定基座，点击右侧 **开启末端控制**。支持 1–24 个模块、自定义轴向和连接方位。控制球以当前实际末端的位置和方向初始化，末端定义为最后一个模块输出对接面。

默认勾选“仅控制位置”，允许姿态自然变化，旋转控件禁用。取消勾选后同时约束位置与姿态，开放以下旋转操作；切换模式会将目标贴合当前末端。位置模式仅要求位置误差不超过0.5mm，显示的姿态差不参与收敛判定。不同构型的可达方向不同，开放控制不代表具备六自由度。以下保持姿态的描述适用于完整位姿模式。

- **平移 XYZ**：拖动箭头/平面手柄进行世界坐标平移；拖动球心沿屏幕平面平移，保持目标姿态。
- **旋转 XYZ**：拖动世界坐标旋转环，保持目标位置。也可以输入世界坐标 X/Y/Z（米）与 XYZ 欧拉角 Roll/Pitch/Yaw（度）。内部使用四元数避免姿态误差计算的角度跳变。
- **贴合当前末端**：从实际关节位置重新设置控制球，清除不可达目标。
- 暂停时直接显示求解姿态；动力学运行时只发送位置伺服目标。控制球为目标，不代表机器人已在动力学中到达。
- 采用有界阻尼最小二乘逆运动学，遵守关节限位。收敛阈值为位置0.5mm、姿态0.01rad。未收敛时球变红，保留上一组有效关节目标。
- 经典参考 q 位于部分运动方向受限的姿态附近；固定姿态的平移或固定位置的旋转可能无法实现。求解是局部方法，未收敛不等于全局不存在解；本功能不含碰撞避障。
- 重置、切换构型、改变物理模型，或操作步态/手动关节时会退出末端控制，避免控制目标冲突。对所有固定基座串联构型的自动生成模型开放；自由基座与自定义 XML 暂不支持。

实现：`src/utils/inverseKinematics.ts`（求解）、`src/utils/armTargetControl.ts`（三维交互）、`src/components/ArmControlPanel.tsx`（控制面板），接入 `App.tsx` 与 `SimulationViewport.tsx`。复用已有 Three.js，无新增依赖。

新增连接结构保留 106 mm 零位安装节距，横向关节壳体轴沿局部 X/Y，扭转关节沿局部 Z；输入壳体随上游、输出叉架随本关节转动。YuMi 风格是概念轴系，不是 ABB 原机复刻。`results/architecture-comparison` 的数据仍对应旧半圆柱模型，不能直接用作新结构的负载／碰撞结论。±180°是仿真关节限位，不代表连接件已验证全行程无干涉。
